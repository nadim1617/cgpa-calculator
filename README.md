# 🎓 BD CGPA Calculator

A modern, responsive **CGPA Calculator for University Students in Bangladesh**, built with **React.js** and deployed on **Vercel**.

This web app allows students to calculate their CGPA accurately using **university-specific grading systems**, with a clean UI, dark mode support, and persistent data.

---

## 🌐 Live Demo
👉 https://bd-cgpa-calculator.vercel.app/

---

## ✨ Features

- ✅ Supports multiple Bangladeshi universities
- 🎯 University-specific grading systems
- 🧮 Accurate CGPA calculation with credit hours
- 🌙 Dark / Light mode (saved automatically)
- 💾 Course data saved per university (localStorage)
- 📱 Fully responsive (mobile & desktop)
- ⬆️ Scroll-to-top button
- 🧊 Modern UI with animations & hover effects

---

## 🏫 Supported Universities

- Daffodil International University (DIU)
- American International University-Bangladesh (AIUB)
- BRAC University
- North South University (NSU)
- East West University (EWU)
- United International University (UIU)

(More universities can be added later.)

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** CSS (SF Pro system font)
- **State Management:** React Hooks
- **Storage:** Browser LocalStorage
- **Deployment:** Vercel
- **Version Control:** Git & GitHub
